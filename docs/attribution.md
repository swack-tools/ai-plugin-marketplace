# Source attribution

The catalog imports selected documentation and metadata from these projects:

- [Vale](https://github.com/swack-tools/vale-ai-plugin), licensed under MIT.
- [Trakt MCP](https://github.com/swack-tools/trakt-ai-plugin), licensed under GPL-3.0-only.
- [Token Max](https://github.com/swack-tools/token-max-ai-plugin), with no standalone license file in the inspected source.

Generated pages link to the exact source commits used for their content. Small
wording corrections are recorded in `catalog/prose-edits.json`; the original
text remains available through those links. Capability examples describe
expected behavior and are not execution transcripts.

Fixtures preserve the upstream license files where provided. Trakt's complete
license is included at `tests/fixtures/catalog/trakt-mcp/LICENSE`. The Vale
checker and bundled Google rules remain in a separate pinned tooling checkout.
The site design and generator are maintained in this repository.
