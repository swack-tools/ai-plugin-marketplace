# Plugin marketplace

A shared marketplace for Vale, Trakt MCP, Token Max, and Colab Pilot plugins
for Claude, Codex, and Antigravity. Add `swack-tools/ai-plugin-marketplace` in
your client's marketplace settings, then install the plugins you want.

See the [catalog and installation guide](https://ai.swacktech.com/) for capabilities,
examples, and available release downloads.
